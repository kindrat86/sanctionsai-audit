Before you go

Questions builders ask.

Is this actually real compliance, or a toy? +
The data is the live OFAC SDN list — the same one your bank screens against. We wrap it for the agent protocol and put a $10,000 guarantee behind it. Verify any flagged wallet yourself with one curl command before you pay us a cent.
Do I have to hand over custody or keys? +
No. Screening is stateless and read-only. You send a wallet address, we return a boolean. No keys, no custody, no contract. The agent still signs and submits the tx — we just tell it whether to.
How fast is it, really? +
P95 latency is under 100ms from us-east. It runs synchronously in your payment path without your user ever noticing. Fail-closed by default — if we can't answer in time, the tx halts, not the user.
What if I'm on the free tier — am I still protected? +
The screening is identical across tiers. Free gives you 5 checks/day to test and prototype. When you ship to production, move to Dev ($19) for the $10k guarantee, audit receipts, and 10k checks/mo.
Can I self-host? +
Yes. pip install sanctions-mcp runs the same engine locally via MCP. The hosted API exists for when you want the SLA, the guarantee, and always-current SDN updates without operating it yourself.
